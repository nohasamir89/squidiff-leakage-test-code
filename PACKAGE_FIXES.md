# Changes to this package copy (21 Oct 2026)

Made after a full verification of the package against the manuscript draft (see the verification
report). None of these changes alters any computed result: the statistical code was checked and
left untouched; the edits are packaging completeness, guards, dead code, comments and paths.
`MANIFEST.csv` was **not** regenerated here, so `tests/test_package.py::test_manifest_sha256`
lists exactly the files below as CHANGED until the package is rebuilt from the repository.

Apply each edit to the repository at tag `manuscript-v1` (the original path of every file is in
`MANIFEST.csv`), commit, rebuild the package with `build_manuscript_package.py`, and run
`python -m pytest` on the result.

`apply_package_fixes.py` does the copying: `python apply_package_fixes.py` prints the plan,
`--apply` copies with backups. It overwrites a repository file only if that file still has the
sha256 recorded in `MANIFEST.csv`, so nothing changed after the build can be lost. Applied to the
repository on 21 Oct 2026: branch `code-tests`, commit `80dcdce` (26 files, 0 skipped).

Two package-root files are generated by the build and were therefore not copied: `README.md` and
`FIGURE_MAP.md`. `build_manuscript_package.py` was then changed (section F) so that the regenerated
`README.md` carries the "Tests" section and the running notes, and `FIGURE_MAP.md` comes from
`manuscript_code_inventory.md`, whose fig1b row has to be updated in the repository (the package's
`FIGURE_MAP.md` is that file plus the one-row edit).
